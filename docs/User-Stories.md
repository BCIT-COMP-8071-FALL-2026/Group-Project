# User Stories
## OLTP User Stories
|Epic | User Story | Acceptance Criteria| 
|-------|---------|---------|
|User Accounts and Login| As a user I want to be able to login so that I can information that pertains to me. | <ul><li> Warning System <ul> <li>Attempts 1-2: error message only</li> <li>Attempt 3: warning</li> <li>Attempt 5: account locked until email reset </li> </ul> <li>Successful login will show the home page</li> <li>Unsuccessful login will show a warning</li></ul>|
||As a user I want to be able to easily set up a secure account so that I can keep of my personal information.|<ul><li>Password is encrypted and stored safely</li><li>Form contains boxes for:<ul><li>First Name (R) </li><li>Middle Name (O)</li><li>Last Name (R)</li><li>Email Address (R)</li><li>Phone number (R)</li><li>Address (R) <ul><li>Ensure Street, City, Country, Province, Postal Code are separate boxes</li><li>Add auto-fill eventually?</li></ul></ul><li>Insurance (O)<ul><li>Company</li><li>Account #</li></ul></li> <li>Password and email are stored and encrypted in the database</li><li>Selection option for Patient or Family </li> </ul>|
||As a user I want my sessions to be secure so that I can have safe of mind that my data is protected.|<ul><li>Cookie sessions implemented</li><li>Session expires after 30 minutes of inactivity</li><li>Logout and Login are secured</li><li>Patient pages should not be accessible without the correct accounts</li>|
|User Roles and Permissions | As the admin, I want to be able to turn employee accounts into moderators through a button locked by a passkey so that I can easily let them work and be secure.|<ul><li>Button to turn account into moderator pops up a password</li><li>Successful password will turn account into moderator </li><li>Unsuccessful password will do nothing until 3 attempts, which will issue a warning</li><li>5 attempts will log the admin out</li></ul>|
||As an admin, I want a clear hierarchy of roles and permissions so that I can ensure proper access to all users.|<ul><li>All roles are defined</li><li>All permissions are defined for each role</li><li>Permissions following least privilege only philosophy<ul><li>Only give each role what that role requires to work. Otherwise do not give them that permission.</li></ul></li></ul>|
|Senior Profile Management|||
|Create|As a user I want to input my personal data so that it can be used for future appointments and treatments|<ul><li>Form information<ul><li>SIN number</li><li>Birthday</li><li>Current Doctor</li><li>Emergency Contact</li><li>Power of Attorney</li><li>Current Medication</li></ul></li><li>Information should be encrypted and secure</li><li>User can add family or caretakers that require information on their health, using caretaker/family account id</li></ul>|
|Read|As a user I want to see all my personal data so that I can keep track of it.|<ul><li>Full information<ul><li>First Name</li><li>Middle Name</li><li>Last Name</li><li>Email Address</li><li>Phone number</li><li>Address</li> <li>SIN number [Last 3 digits shown only]</li><li>Birthday</li><li>Current Doctor</li><li>Emergency Contact</li><li>Power of Attorney</li><li>Current Medication</li></ul></li><li>Sensitive information that shouldn’t be shown in public should be hidden except a portion</li></ul>|
|Update |As a user I want to update personal information so that it is up to date.|G = Greyed out/Can’t update </br><ul><li>Full information<ul><li>First Name [G]</li><li>Middle Name [G]</li><li>Last Name [G]</li><li>Email Address</li><li>Phone number</li><li>Address</li><li>SIN number [Last 3 digits shown only] [G]</li><li>Birthday [G] </li><li>Current Doctor</li><li>Emergency Contact</li><li>Power of Attorney</li><li>Current Medication</li></ul></li><li>If user requires any changes due to mistakes when creating/inputting information, requires customer support</li></ul>|
|Delete|As a user I want to be able to deactivate my account if it is no longer needed so that I don’t have to worry about the account any more.| <ul><li>Delete does not delete, archived senior data is retained for 5 years</li><li>Option to permanently archive</li><li>Delete does not happen instantaneously</li><li>Removes user account from active to deactivated.</li></ul>|
|Family and Emergency Contact Assignment|As a family member I want to leave my number so I can be contacted during emergencies.|<ul><li>Emergency contact form can be filled in the profile<ul><li>Contains:<ul><li>First name</li><li>Last name</li><li>Phone number</li><li>work phone number (optional)</li><li>relationship</li></ul></li></ul></li><li>Can have multiple emergency contacts</li><li>If emergency contact has an account, can be assigned as emergency contact as well.</li></ul>|
||As a family member I want to check on my grandparent/parent health and notes from caretakers and doctors so I can make sure they’re okay and follow any instructions that have been left.|<ul><li>Family member creates separate login</li><li>Family ID is added to the patient’s account to view patient information</li><li>Only able to access assigned patient information</li><li>Same home page as a normal account, just added tab for parent/grandparent information</li><li>Assignment to elder account requires elder account login password</li></ul>|
|Caregiver Assignment|As a caregiver I want to see all the patients I have been assigned so that I can manage my time and make it to each appointment.|<ul><li>List of patients displayed in order of appointment times </li><li>Table format<ul><li>Time</li><li>Patient Name</li><li>Appointment Type</li><li>Resident address</li><li>Destination address (if applicable)</li></ul></li><li>Any notes from previous caretakers on a patient</li></ul>|
||As an admin I want to be able to assign qualifying caretakers to my patients so that I can ensure their needs are met.|<ul><li>List of patients displayed</li><li>Searchable by patient name</li><li>Drop down for eligible caretakers<ul><li>Eligibility:<ul><li>Trained</li><li>Time availability</li></ul></li><li>May cull caretakers list in the backend and only display eligible caretakers in the frontend</li></ul></li><li>Separate list for patients who do not have assigned caregivers for admin to work through.</li></ul>|
|Visit Logging and History|As a caregiver I want to be able to check-in and out when I reach my patient’s location and after I’m done so that my boss knows when I started and finished.|<ul><li>In list of patients (Caregiver Assignment) user is able to select the patient in question to enter another page where they can log their activity</li><li>Check in button, check-out button</li><li>Logs the time of arrival and time of checkout and this is registered in the database as well</li></ul>|
||As a caregiver I want to be able to leave notes under my patients account so that future caretakers know what to expect or what to do better.|<ul><li>In list of patients (Caregiver Assignment) user is able to select the patient in question to enter another page where they can log their activity</li><li>Expandable text box that is available in the same window as the check-in/check-out</li><li>Use a button to save</li><li>Caretakers cannot erase previous caretaker notes</li><li>Only most recent (within 7 days) will show.</li><li>Can archive older notes</li><li>(If there is a potential for AI, it would be good to use it here to monitor for abusive language or detrimental notes on the patient to prevent patient abuse)</li></ul>|
