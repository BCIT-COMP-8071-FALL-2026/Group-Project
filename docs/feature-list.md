| Feature | Priority |
|---|---|

| User Roles and Permissions | **Must** |
| Senior Profile Management (CRUD) | **Must** |
| Family and Emergency Contact Management | **Must** |
| Caregiver Assignment | **Must** |
| Visit Logging and History | **Must** |
| Medical Condition Management (fields on the profile) | **Should** |
| Medication Management (basic) | **Should** |
| Healthcare Professional Management | Nice-to-have |
| Insurance Information Management | Nice-to-have |
| Appointment Management | Nice-to-have |
| Power of Attorney Information | Nice-to-have |

| Profile Picture | Nice-to-have |
